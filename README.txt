SKEIN FOR IPHONE (no App Store)
===============================
1. Make a free GitHub account, then create a NEW repository named skein-web.
   Choose PUBLIC (free GitHub accounts can only host websites from public repos).
2. Upload every file in this folder (drag them in), then click Commit changes.
3. Repository Settings > Pages > "Deploy from a branch" > branch main, folder / (root) > Save.
4. After about a minute, your site is at  https://YOUR-USERNAME.github.io/skein-web/
5. On each iPhone, open that address in SAFARI, tap Share > Add to Home Screen > Add.
6. Open Skein from the new home screen icon (not from Safari) and allow camera and microphone.

No GitHub? Drag this folder onto app.netlify.com/drop for a free web address instead.
